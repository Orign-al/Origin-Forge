# H100 入站访问策略建议

当前阶段不修改防火墙，也不开放公网端口。`10.82.36.1` 是私有地址，但仍应由上游网络和未来经批准的主机防火墙共同限制。

## 当前允许的用途

- TCP 22：宿主 SSH，仅允许公司管理网/跳板来源。
- TCP 22022：`gpu-dev-codexops` 测试 SSH，仅允许公司管理网；后续每个用户端口必须单独分配、登记和审计。
- TCP 3000/9090/9100/9400：保持 `127.0.0.1`，通过 SSH 本地转发查看，不直接对局域网或公网开放。
- MariaDB 与 DCGM hostengine：保持 localhost。
- Slurm 6817-6819：当前单机使用；加入第二节点前，根据实际控制/计算方向仅允许集群管理网。

Grafana 的建议访问方式：

```bash
ssh -L 3000:127.0.0.1:3000 h100-codex
```

## 后续审批事项

在启用 UFW/nftables 或对外开放任何监控/Slurm API 前，管理员应批准精确的源网段、目标端口、IPv4/IPv6 策略、回滚命令和带外恢复路径。Mellanox CRC/symbol error P0 未关闭前，不批准正式 NFS、第二节点、跨节点 NCCL 或高速共享存储。
